1. Token GitHub

Diperlukan untuk menyimpan inspeksi baru dari perangkat ini (token tidak diperlukan hanya untuk melihat hasil lewat QR). Buat token di GitHub → Settings → Developer settings → Fine-grained tokens, dibatasi ke repo asset-registration ini saja, dengan izin Contents: Read and write. Token disimpan hanya di penyimpanan lokal browser ini, tidak dikirim ke tempat lain selain GitHub.

2. Export Semua Inspeksi

Mengumpulkan semua inspeksi yang sudah tersimpan di branch data pada repo ini, lalu membuat satu file .xlsx dengan seluruh data terisi, foto inspeksi, dan QR code sebagai gambar yang tertanam di tiap baris. Proses berjalan di browser ini, bisa memakan waktu beberapa menit tergantung jumlah data.

3. Data Tersimpan

Daftar semua inspeksi yang sudah tersimpan di branch data. Edit untuk memperbaiki data yang salah isi (nama sub komponen dan foto tidak bisa diubah di sini), atau Hapus untuk menghapus inspeksi (termasuk foto) secara permanen dari repo.
