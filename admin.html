1. Token GitHub

Diperlukan untuk menyimpan inspeksi baru dari perangkat ini (token tidak diperlukan hanya untuk melihat hasil lewat QR). Buat token di GitHub → Settings → Developer settings → Fine-grained tokens, dibatasi ke repo asset-registration ini saja, dengan izin Contents: Read and write. Token disimpan hanya di penyimpanan lokal browser ini, tidak dikirim ke tempat lain selain GitHub.
